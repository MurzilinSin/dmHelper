# dmHelper

Локальный Android-помощник мастера D&D. Первая версия приложения — трекер одного активного боя.

## Запуск

Открой репозиторий в Android Studio, установи Android SDK 36 и выбери конфигурацию `presentation`. Приложение поддерживает Android 7.0 (API 24) и выше. Для сборки из терминала понадобится JDK 17 или 21.

```shell
./gradlew :presentation:assembleDebug :domain:test :presentation:testDebugUnitTest
```

Проверки SQLite и Compose запускаются на подключённом телефоне или эмуляторе.

```shell
./gradlew :data:connectedDebugAndroidTest :presentation:connectedDebugAndroidTest
```

## Проверка трекера

1. Создай бой и через **+** добавь героя с ХП 12 и инициативой 14, затем гоблина с ХП 8 и инициативой 18.
2. Зажми ручку справа в строке гоблина и перетащи его под героя. Инициатива останется 18. При добавлении нового участника ранее выставленный относительный порядок участников сохраняется.
3. Начни бой. Герой получит первый ход. Нажми **Следующий ход**, чтобы активировать гоблина. Нажми на ХП гоблина и измени значение.
4. Поверни телефон, затем закрой и снова запусти приложение. Проверь порядок, ХП, текущий ход и номер раунда.

## Архитектура

- `domain/` — модели и правила боя на Kotlin/JVM, контракт репозитория.
- `data/` — Room поверх SQLite. Бой и участники хранятся в связанных таблицах. Любое изменение применяется транзакционно. Схема экспортируется в `data/schemas/`.
- `presentation/` — Android-приложение с Jetpack Compose. В MVI интерфейс отправляет `BattleIntent` во ViewModel и отображает `BattleUiState` из `StateFlow`. Hilt связывает ViewModel с репозиторием, корутины выполняют операции с базой.

Версии библиотек закреплены в [каталоге Gradle](gradle/libs.versions.toml). [Рекомендации Android по Room](https://developer.android.com/training/data-storage/room).
